## Sources

- `io.ecodia.skins.bare`: The hello-world skin. Adjusts spacing and corner radius with zero visual opinion. Authored by Ecodia; see `notes/skin-implementations.md` in the TheodiaDesktop repo for the full planned catalog.
- `io.ecodia.skins.air`: Generous whitespace — larger card padding, looser line-height, wider sidebar. Geometry-only: every value lives in the manifest's `layout` block, and the `phone` variant narrows them for small screens, so the skin works on every client without client-specific CSS.
